# 搬砖回血

看工资慢慢涨，把时间算清楚。

秒薪计算与打工陪伴工具。卡通小伙伴「砖砖」陪你搬砖，也提醒你记得下班。

## 功能

- 月薪/年收入换算工作时薪、时间成本时薪与秒薪。
- 支持奖金、通勤、休息、不同排班、额外加班和工作支出。
- 两份工作对比，8类交互详情图表。
- 一键上班；实际下班点击「收工回血」，核对、修改无偿时长后结束。
- 到预计下班时间继续计时，默认无偿，也可填写加班单价。
- 陪伴小窗闲置收起、手动隐藏；隐藏后保留砖砖与回血条。
- 支持浏览器的网页画中画跨窗口悬浮；不支持时回退到页内小窗。
- 分享图片默认隐藏收入；用户数据存于本机浏览器。

## 计算口径

工作时薪 = 年到手收入 ÷ 全年实际工作小时。

时间成本时薪 = 年到手收入 ÷ 全年工作相关占用小时（按设置计休息、通勤）。

正常时段以锁定秒薪折算；超时按所设加班单价另计，默认0元。工资固定时，计时金额仅是时间折算，并不代表实时到账。无偿时长人工修正不改正常收入或已有有偿加班金额。

## 本地运行与验证

直接用浏览器打开 `index.html`，不依赖网络图片、第三方脚本或后端。

需要本地HTTP地址时，在项目目录运行：

```bash
python -m http.server 8000
```

打开 `http://localhost:8000/`。

运行计时及交互逻辑检查：

```bash
npm test
```

测试使用Node模拟DOM和时钟，不能替代真实浏览器的视觉、原生日期弹窗及画中画兼容验证。

## 部署至 GitHub Pages

1. 创建公开仓库 `banzhuan-huixue`。
2. 上传本目录内容；`index.html` 应在仓库根目录。
3. 打开 Settings → Pages。
4. Source 选 Deploy from a branch，分支 main，目录 /(root)，保存。
5. 发布完成后使用 Pages 给出的HTTPS链接。

## 数据与兼容

- 工资、排班和历史记录保存在当前浏览器，不上传GitHub；更换浏览器或清理站点数据后不会自动恢复。
- 本地文件与线上站点的数据隔离，已有本地记录不会自动迁移。
- 页面打开期间后台继续累计；关闭或刷新会保存并暂停，重新打开需手动继续。
- 浏览器冻结、系统休眠与移动端回收页面的效果，需要真实设备核验。
- 同一站点多个标签页暂未实现统一锁定，使用时请保留一个计时页面。

## 项目结构

- `index.html`：自包含网页与全部动效。
- `tests/runtime.cjs`：公式、计时、人工修正、小窗与上下班按钮逻辑检查。
- `package.json`：测试命令。
- `.nojekyll`：按普通静态文件发布。
